# Часть Нозина: Projects и Blogs

Здесь две секции сайта:
1. **Projects**: «I bring results. My clients are proof.» и карточки проектов, которые можно листать.
2. **Blogs**: «Latest Blogs» и список статей.

---

## Файлы

| Файл | Что внутри |
|---|---|
| `datas.js` | Данные: тексты карточек и статей |
| `projectsSection.jsx` | Секция с проектами и слайдером |
| `blogsSection.jsx` | Секция со статьями |

Обе секции подключены в `src/App.jsx`.

---

## Что использовано и для чего

### React
На нём собран весь сайт. Каждая секция — это **компонент**, то есть функция, которая возвращает HTML-разметку (JSX).

### Tailwind CSS
Стили пишутся прямо в `className`, отдельный CSS-файл не нужен.

- `max-w-325 mx-auto`: блок шириной до 1300px по центру
- `flex`: элементы в ряд
- `flex-col`: элементы друг под другом
- `justify-between`: элементы разносятся по краям
- `gap-4`: отступ между элементами
- `text-[54px]`: размер шрифта
- `font-bold`: жирный текст
- `bg-black`, `text-white`: чёрный фон, белый текст
- `uppercase`: все буквы заглавные
- `border-b`: линия снизу

### Swiper
Библиотека для **слайдера**, чтобы карточки проектов листались кнопками ‹ ›.

- `slidesPerView={2.5}`: видно 2,5 карточки
- `spaceBetween={24}`: расстояние между карточками
- `navigation`: какие кнопки листают слайдер (`.projects-prev` и `.projects-next`)

### lucide-react
Библиотека **иконок**. Отсюда стрелки:
- `ArrowRight`: стрелка → у ссылок
- `ChevronLeft` и `ChevronRight`: стрелки ‹ › на кнопках слайдера

### Button
Готовая кнопка из `src/components/Button.jsx`. Использована для «View all projects», чтобы не писать новую.

## Как это работает

### 1. Данные отдельно
В `datas.js` лежат два массива: `projects` и `blogs`. Один объект в массиве — одна карточка или одна статья.

Чтобы добавить новую статью, достаточно добавить объект в массив, код трогать не нужно.

### 2. `.map()` рисует карточки
```jsx
{blogs.map(elem => (
  <article key={elem.id}>
    <h3>{elem.title}</h3>
  </article>
))}
```
`.map()` проходит по массиву и для каждого объекта создаёт карточку.
`key` нужен React, чтобы отличать карточки друг от друга.

### 3. Фон наполовину белый, наполовину чёрный
В макете карточки проектов стоят на границе белого и чёрного фона. Это сделано градиентом:
```
bg-[linear-gradient(to_bottom,white_70%,black_70%)]
```
До 70% высоты фон белый, дальше чёрный.

### 4. Картинки проектов
Сейчас вместо картинок стоят цветные градиенты (поле `bg` в `datas.js`).
Потом их можно заменить картинками из Figma.

## Где что на странице

**Projects**
- Слева заголовок, справа кнопка «View all projects»
- Ниже слайдер с карточками: картинка, категория (синим), название, «View Project →»
- Под слайдером справа кнопки ‹ ›

**Blogs**
- Слева: «BLOGS» (оранжевым), «Latest Blogs», «View all →»
- Справа: список статей. У каждой дата, время чтения, заголовок, «Read the article →» и линия снизу
